Ardu

A personal project exploring prompt engineering and LLM evaluation — built as a working mobile app to make the experiments real.

Node.js · PostgreSQL · Ollama (local LLM) · React Native · Expo

🤖 Prompt Engineering

Quotes are generated by a locally-hosted LLM (Ollama + qwen2.5) running on a 2GB VPS. Prompts were iteratively designed and validated — balancing specificity, originality, and model constraints.

✨ Random Delivery

Receive quotes at unexpected moments throughout your day — surprise motivation when you need it.

📝 Daily Reflections

Write personal reflections on each quote. Track your growth and build self-awareness over time.

📊 Streak Tracking

Build consistency with daily engagement streaks. Stay motivated and watch your progress grow.

☁️ Cloud Sync

Your quotes, favorites, and reflections automatically sync across all your devices.

🌍 Multi-Language

Available in English and Spanish. More languages coming soon.

Behind the AI

The real project is the engineering underneath — designing a prompt pipeline that works under real constraints.

📐 Constraint-Driven Prompting

Running a 1.5B model on a 2GB VPS means every prompt token matters. Prompts were designed to maximise relevance with minimal context: short instructions, no examples.

📊 LLM Evaluation Framework

Built an eval harness where an LLM judge (a local 8B model, with Claude as a second opinion) scores generated quotes on relevance, originality, inspiration, and clarity. Each prompt change is measured — not guessed.

🔁 Multi-Step Generation

Generation uses a two-gate pipeline: a word-overlap check (rejects quotes that just echo the user's own words) and a similarity check (rejects near-duplicates of quotes already in the pool).

🔬 Iterative Tuning

Prompt versions are tracked with before/after scores, re-measured with 20 motivations × 3 runs, a stronger judge and a blind human check. The tuned prompt made quotes clearer; naming banned clichés in the prompt made the 1.5B model use them more.
