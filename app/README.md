# Ardu app (React Native / Expo)

The mobile client: daily quotes, a reflection journal, streaks, push
notifications, and AI-generated quotes from the backend. English and Spanish
(Guaraní translations are partial).

Stack: Expo SDK 54, React Native 0.81, Zustand, React Navigation, i18next,
`react-native-google-mobile-ads`.

## Run it

Needs the backend running (see [../backend](../backend/README.md)) and Xcode or
Android Studio. The app uses native modules (ads, share, file system), so it
runs as a development build, not in Expo Go.

```bash
cd app
npm install
cp .env.example .env       # points at http://localhost:3000 by default
npx expo run:ios           # or: npx expo run:android
```

The native `ios/` and `android/` folders are generated by `expo prebuild`
(Continuous Native Generation) and are not committed.

## Configuration

Everything account-specific comes from `.env` (see `.env.example`):

| Variable | Purpose | Default when empty |
|---|---|---|
| `API_BASE_URL` | Backend URL | `http://localhost:3000` |
| `ADMOB_APP_ID_IOS` / `_ANDROID` | AdMob app IDs (build time) | Google's sample app IDs |
| `ADMOB_BANNER_ID_IOS` / `_ANDROID` | Banner unit IDs for release builds | Google's test banner |
| `EAS_PROJECT_ID` | EAS project (only for EAS builds and Expo push tokens) | unset: push tokens unavailable |

Dev builds always show Google's test ads, so building this repo never serves
real ads on anyone's account.

## Layout

```
screens/      main screens (quotes dashboard, journal, settings, onboarding)
components/   modals, buttons, streak counter, cards
src/api/      axios client with JWT refresh, API services
src/store/    Zustand stores (auth, quotes)
services/     reflections and streak API calls
constants/    translations (en, es, gn)
```
